# سوق دير الزور المفتوح

أول سوق إلكتروني مفتوح في دير الزور للإعلانات المبوبة — بيع وشراء مباشر بين المستخدمين.

## المميزات

- **إعلانات مبوبة**: نشر، تعديل، حذف، تجديد، وضع "تم البيع"
- **بحث وتصفية متقدمة**: بحث نصي، فلاتر (الفئة، المنطقة، السعر من-إلى)، ترتيب (الأحدث، السعر، الأكثر مشاهدة)
- **حسابات المستخدمين**: تسجيل، دخول، استعادة كلمة مرور، تعديل البيانات
- **المفضلة**: حفظ الإعلانات في الحساب
- **محادثة فورية**: مراسلة مباشرة بين البائع والمشتري مع عدّاد الرسائل غير المقروءة
- **لوحة مدير**: إحصائيات ورسوم بيانية، إدارة الإعلانات (تفعيل/إخفاء/تمييز/حذف)، إدارة المستخدمين (حظر)، البلاغات، إعدادات التواصل
- **مشاركة واتساب/هاتف**: زر واتساب واتصال مباشر من كل إعلان
- **PWA**: قابل للتثبيت على الجوال، يعمل دون إنترنت بعد أول تحميل
- **واجهة عربية RTL** بتصميم عصري متجاوب

## البنية التقنية

| المكوّن | التقنية |
|---|---|
| الواجهة | React 18 + Vite |
| الخادم | Node.js + Express |
| قاعدة البيانات | SQLite (better-sqlite3) |
| المصادقة | JWT + bcrypt |
| رفع الوسائط | Multer + تخزين محلي |

**كل الخدمات مجانية 100% — بدون أي اشتراكات مدفوعة.**

## التشغيل

```bash
# تشغيل الخادم والواجهة معاً
./start.sh

# أو يدوياً:
cd backend && npm install && npm start   # على المنفذ 3001
cd frontend && npm install && npm run dev # على المنفذ 5173 (مع بروكسي /api للخادم)
```

ثم افتح `http://localhost:5173`

## البنية

```
backend/
  src/
    server.js        # نقطة الدخول
    db.js            # قاعدة البيانات + البذور التجريبية
    auth.js          # JWT
    routes-auth.js   # تسجيل/دخول/ملف
    routes-ads.js    # إعلانات + مفضلة + بلاغات
    routes-chat.js   # محادثة
    routes-admin.js  # لوحة المدير
  data/              # ملف SQLite (ينشأ تلقائياً)
  uploads/           # صور/فيديوهات الإعلانات
frontend/
  src/
    pages/           # الصفحات
    components/      # المكونات
    contexts/        # حالة المصادقة
    App.jsx          # التوجيه
```

## تصفير قاعدة البيانات

لإعادة تعيين البيانات إلى الحالة التجريبية:

```bash
cd backend/data && mv souq.db souq.db.bak
# ثم أعد تشغيل الخادم (سيعيد إنشاء قاعدة البيانات)
```

## ملاحظات النشر (اختياري)

النسخة الحالية تعمل محلياً ببيانات مجانية بالكامل. للنشر على الاستضافة السحابية يمكن:
- الواجهة على **Vercel** (خطة مجانية) والواجهة الأمامية تنادي API خارجياً
- الخادم على **Render/Railway** (خطط مجانية) أو استبدال SQLite بقاعدة سحابية مجانية مثل Supabase
