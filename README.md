# 🛒 سوق دير الزور المفتوح

أول سوق إلكتروني للإعلانات المبوّبة في دير الزور.

## 🛠️ التقنيات
- HTML5 + CSS3 + JavaScript (Vanilla)
- Firebase (Authentication + Firestore)
- Cloudinary (رفع الصور)

## 📁 الهيكل
- `index.html` — الصفحة الرئيسية
- `src/styles/` — التصميم
- `src/config/` — إعدادات Firebase
- `src/features/` — الميزات (إعلانات، مصادقة، رسائل، إدارة)
- `src/components/` — مكوّنات الواجهة
- `src/app.js` — نقطة التشغيل
