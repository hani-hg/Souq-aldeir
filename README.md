# سوق دير الزور المفتوح

أول سوق إلكتروني مفتوح في دير الزور للإعلانات المبوبة — بيع وشراء مباشر بين المستخدمين.

## المميزات

- **إعلانات مبوبة**: نشر، تعديل، حذف، تجديد، وضع "تم البيع"
- **بحث وتصفية متقدمة**: بحث نصي، فلاتر (الفئة، المنطقة، السعر من-إلى)، ترتيب (الأحدث، السعر، الأكثر مشاهدة)
- **حسابات المستخدمين**: تسجيل، دخول، استعادة كلمة مرور، تعديل البيانات
- **المفضلة**: حفظ الإعلانات في الحساب
- **محادثة فورية**: مراسلة مباشرة بين البائع والمشتري مع عدّاد الرسائل غير المقروءة
- **لوحة مدير**: إحصائيات ورسوم بيانية، إدارة الإعلانات (تفعيل/إخفاء/تمييز/حذف)، إدارة المستخدمين (حظر)، البلاغات، إعدادات التواصل
- **مشاركة واتساب/هاتف**: زر واتساب واتصال مباشر من كل إعلان
- **PWA**: قابل للتثبيت على الجوال، يعمل دون إنترنت بعد أول تحميل
- **واجهة عربية RTL** بتصميم عصري متجاوب

## البنية التقنية

| المكوّن | التقنية |
|---|---|
| الواجهة | React 18 + Vite |
| قاعدة البيانات | Firebase Firestore (سحابية، مجانية) |
| المصادقة | Firebase Authentication (بريد/هاتف وكلمة مرور) |
| رفع الوسائط | Cloudinary (رفع مباشر من المتصفح، مجاني) |
| الاستضافة | Vercel (ثابت، مجاني) |

**كل الخدمات مجانية 100% — بدون أي اشتراكات مدفوعة.**

الموقع نسخة **عميل كامل** (Serverless): المتصفح يتصل مباشرة بـ Firebase و Cloudinary، فلا حاجة لخادم وسيط. `frontend/src/api.js` يقدم طبقة بيانات تحاكي واجهة REST بحيث تبقى الصفحات بسيطة.

## التشغيل

```bash
cd frontend && npm install && npm run dev
```

ثم افتح `http://localhost:5173`

## النشر على Vercel

المستودع جاهز للنشر عبر `vercel.json` (يبني الواجهة وينشرها كموقع ثابت). إعدادات Firebase مضمّنة في الكود (مفاتيح عامة آمنة للاستخدام من المتصفح).

## البنية

```
frontend/
  src/
    firebase.js      # إعداد Firebase (المشروع: souq-aldeir)
    api.js           # طبقة البيانات فوق Firestore (تحاكي REST)
    pages/           # الصفحات
    components/      # المكونات
    contexts/        # حالة المصادقة
    App.jsx          # التوجيه
```

## ملاحظة

النسخة القديمة من الموقع (ملفات HTML/JS في جذر المستودع) لم تعد تُستخدم في النشر — النشر يتم فقط من `frontend/dist`. يمكن حذفها من المستودع عند الرغبة.
