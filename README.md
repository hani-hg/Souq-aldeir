## ⚙️ الإعدادات التي قد تحتاج تعديلها

كل الإعدادات القابلة للتغيير موجودة في **مكان واحد**: `src/js/firebase.js`

```js
const CONFIG = {
  CLOUDINARY_CLOUD: 'dzjy5tubx',        // اسم حساب Cloudinary لرفع الصور
  CLOUDINARY_PRESET: 'souq_ads',        // اسم الـ upload preset
  WHATSAPP_NUMBER: '963XXXXXXXXX',      // رقم واتساب الإدارة (لطلبات التمييز)
  ADMIN_SETUP_CODE: 'SOUQ2025ADMIN'     // الرمز السري لتفعيل أول حساب مدير
};
```

## 🛡️ كيف تصبح مديراً لأول مرة

1. أنشئ حساباً عادياً من الموقع
2. اذهب لـ **حسابي** ← اضغط **"إعداد صلاحية المدير"**
3. أدخل الرمز السري الموجود في `CONFIG.ADMIN_SETUP_CODE`
4. أعد تحميل الصفحة — ستظهر لك أيقونة 🛡️ وتقدر تفتح `admin.html`

## 🔥 Firebase — خطوات إلزامية

1. **Authentication ← Sign-in method** ← فعّل "Email/Password"
2. **Firestore Database** ← أنشئ قاعدة البيانات إن لم تكن موجودة
3. **Firestore ← Rules** ← الصق محتوى ملف `firestore.rules` في هذا المشروع

## 🖼️ Cloudinary — رفع الصور

المشروع يستخدم Cloudinary (مجاني) بدل Firebase Storage (مدفوع).
تأكد من وجود **Upload Preset** غير موقّع (Unsigned) بنفس الاسم في `CONFIG.CLOUDINARY_PRESET`.

## ✏️ كيف تضيف ميزة جديدة (مثال)

بفضل الهيكل المنظم، عدّل ملفاً واحداً فقط حسب نوع التغيير:

| تريد تعديل... | افتح هذا الملف |
|---|---|
| شكل وألوان الموقع | `src/css/style.css` |
| تسجيل الدخول / الحساب | `src/js/auth.js` |
| عرض/نشر الإعلانات | `src/js/ads.js` |
| نظام الرسائل | `src/js/chat.js` |
| لوحة تحكم المدير | `src/js/admin.js` |
| رقم واتساب أو حساب Cloudinary | `src/js/firebase.js` |
