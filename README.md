# سوق دير الزور المفتوح 🛒

أول سوق إلكتروني في دير الزور، يتيح للمستخدمين نشر إعلاناتهم مجاناً، مع إمكانية تمييز الإعلانات مقابل رسوم رمزية.

## المميزات
- ✅ نشر إعلانات مع الصور
- ✅ تصنيف الإعلانات حسب الفئة
- ✅ نظام مفضلة (حفظ الإعلانات)
- ✅ دردشة مباشرة بين البائع والمشتري
- ✅ لوحة تحكم للمدير
- ✅ إشعارات فورية (Toast)
- ✅ سلايدر للإعلانات المميزة
- ✅ متوافق مع الجوال والكمبيوتر

## التقنيات المستخدمة
- HTML5, CSS3, JavaScript (ES Modules)
- Firebase (Authentication, Firestore)
- Cloudinary (رفع الصور)
- Vercel (النشر)
