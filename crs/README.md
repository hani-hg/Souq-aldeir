# سوق دير الزور المفتوح

أول سوق إلكتروني في دير الزور، يسمح للمستخدمين بنشر إعلاناتهم مجاناً، مع إمكانية تمييز الإعلانات مقابل رسوم رمزية.

## المميزات
- نشر إعلانات مع الصور
- تصنيف الإعلانات حسب الفئة
- نظام مفضلة
- دردشة مباشرة بين البائع والمشتري
- لوحة تحكم للمدير لإدارة الإعلانات وطلبات التمييز
- إشعارات فورية (Toast)
- سلايدر للإعلانات المميزة

## التقنيات المستخدمة
- HTML5, CSS3, JavaScript (ES Modules)
- Firebase (Authentication, Firestore)
- Cloudinary (رفع الصور)
- Font Awesome 6

## التنصيب المحلي
1. قم بنسخ المستودع.
2. قم بتثبيت Firebase CLI إذا أردت اختبار القواعد محلياً.
3. افتح `index.html` في المتصفح (يفضل استخدام Live Server).

## النشر
- يمكن نشر الموقع بسهولة على Vercel أو Firebase Hosting.
- تأكد من تحديث قواعد Firestore و Cloudinary.

## الملاحظات
- تستخدم الصفحة نظام `type="module"` لذا يجب تشغيلها عبر خادم (ليس مباشرة من الملف).
- بيانات تسجيل الدخول التجريبية: admin@souq.com / admin123
